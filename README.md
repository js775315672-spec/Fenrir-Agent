# Fenrir

## 독립 운영 계약 v3.1

Fenrir는 기술적 주장을 직접 선정하고 가설의 전제를 검토해 재현 가능한 반례를 찾는다. 별도 실행에서 재현된 반례 비율과 무효 반박 비율을 분모와 함께 기록한다.

[운영 명세와 원장 사용법](docs/ofc-v3.1.md)
